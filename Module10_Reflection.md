# Module 10 Reflection

In Module 10, I learned how to improve the security of my FastAPI calculator application. I used SQLAlchemy to create a user model, Pydantic to validate user information, and Argon2 to protect passwords.

I also learned how to test my application with PostgreSQL and automate testing using GitHub Actions. I used Docker to build the application and Trivy to check for security vulnerabilities.

The biggest challenge was fixing GitHub Actions errors. I had problems with Python dependencies, security vulnerabilities, and end-to-end tests. I solved these problems step by step by checking error messages, updating packages, and testing my changes.

Finally, all my tests passed, GitHub Actions completed successfully, and my Docker image was published to Docker Hub.
