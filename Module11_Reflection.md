# Module 11 Reflection

In Module 11, I learned how to create a Calculation model using SQLAlchemy and validate data using Pydantic. I also implemented a Factory Pattern to handle addition, subtraction, multiplication, and division. I connected calculations to users through a foreign key.

One challenge was configuring the PostgreSQL connection. I had to fix the database environment settings and use the correct PostgreSQL driver. I also encountered a Pydantic error while creating the schemas, which I fixed by correcting the code structure.

Testing helped me understand how the different parts of the application work together. I wrote new unit and integration tests and reused the existing tests from Module 10. In the end, all 70 tests passed locally with 98% code coverage.

This assignment helped me better understand SQLAlchemy, Pydantic, database relationships, and automated testing. I also learned the importance of making small changes and testing them carefully to avoid breaking existing functionality.
